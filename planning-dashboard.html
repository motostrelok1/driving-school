Алгоритм выбора задачи

1Открыть status/modules.md и найти модуль со статусом частично или запланировано.
2Открыть status/roadmap.md и выбрать ближайший незавершенный этап.
3Открыть tasks/backlog.md и взять первую задачу из нужного раздела.
4Дать ИИ конкретный task-файл, например tasks/audit/auth.md.
5Проверить обновленный task-файл и отчет в tasks/reports/.
6Вернуться в backlog и выбрать следующую маленькую задачу.

Короткая формула: modules → roadmap → backlog → task → report → status → next task.

Типы задач

ТипЧто делаетПример
auditПроверяет текущее состояние без изменения кода.tasks/audit/auth.md
uiМеняет внешний вид и компоненты.Экран управления группами.
logicМеняет бизнес-лгику, хуки, состояния.Смена статуса занятия.
dataМеняет Supabase, типы, миграции.Новые поля группы.
integrationСшивает UI, логику и данные.Создать занятие и показать его ролям.
testsПроверяет сценарии вручную или автотестами.Smoke-сценарии по ролям.

Что читает ИИ Промпт запуска Что пишет ИИ

Что ИИ читает перед началом

  1. AI_TASK_PROMPT.md
  2. TASK_TEMPLATE.md
  3. конкретный task-файл, например tasks/audit/auth.md
  4. docs/project-map.md
  5. docs/mvp-scope.md
  6. status/modules.md
  7. только файлы из раздела Контекст конкретной задачи

Промпт запуска задачи

Выполни задачу из файла:

tasks/audit/auth.md

Работай строго по правилам из:

AI_TASK_PROMPT.md
TASK_TEMPLATE.md

Код не меняй, если в задаче указано, что это audit.
После выполнения обнови task-файл и создай отчет в tasks/reports/.

Что ИИ пишет после выполнения

  1. Обновляет сам task-файл: статус, готовность, результат.
  2. Создает отчет: tasks/reports/<тип>/<название-задачи>.md.
  3. Обновляет status/modules.md, если изменилась готовность модуля.
  4. Обновляет tasks/backlog.md, если появились новые задачи.
