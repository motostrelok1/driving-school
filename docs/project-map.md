# Карта проекта MVP

Проект: PWA для автошколы.

Цель MVP: личные кабинеты ученика, инструктора и администратора с расписанием занятий, базовым управлением пользователями и push-уведомлениями.

## Роли

- student: ученик, видит свое расписание.
- instructor: инструктор, видит свое расписание и закрепленных учеников.
- admin: администратор, управляет пользователями, назначениями и расписанием.

## Экраны

| Экран | Путь | Роль | Состояние |
|---|---|---|---|
| Вход | /login | public | частично готов |
| Регистрация | /register | public | частично готов |
| Редирект по роли | / | auth | частично готов |
| Расписание ученика | /student/schedule | student | базово готово |
| Расписание инструктора | /instructor/schedule | instructor | частично готово |
| Ученики инструктора | /instructor/students | instructor | базово готово |
| Дашборд админа | /admin | admin | базово готово |
| Пользователи админа | /admin/users | admin | частично готово |
| Расписание админа | /admin/schedule | admin | требует проверки |
| 404 | * | public | базово готово |

## Основные модули кода

- src/features/auth: авторизация, профиль, роль.
- src/features/schedule: занятия, список занятий, изменение статуса.
- src/features/instructors: ученики инструктора.
- src/features/admin: пользователи, группы, назначение инструктора.
- src/components: Layout, NotificationButton, UI-компоненты.
- src/lib: Supabase и OneSignal.
- supabase/migrations: схема БД, RLS, функции.

## Главные риски MVP

- Нет тестов.
- Не проверено, что админское расписание действительно показывает все занятия.
- Нет полноценного управления группами.
- UI и логика частично смешаны в страницах.
- Push/PWA требуют проверки в реальной среде.
- Нужно проверить отображение русского текста в браузере и редакторе.
