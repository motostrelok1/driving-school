# Полная очистка старых переписок — подготовка

Пользователь разрешил удалить **все существующие чаты и сообщения**, включая уведомления, но требуется сохранить пользователей, расписание, назначения инструкторов, уроки и учебный прогресс. Новые чаты после смены инструктора должны **навсегда закрываться**, а не удаляться.

## Первый этап: только просмотр

В SQL Editor рабочего Supabase выполнить `supabase/audits/old_chat_history_cleanup_audit.sql`. Он считает строки и показывает все внешние ключи, указывающие на пять таблиц сообщений и задач. Скрипт **ничего не меняет**.

Полученные результаты проверить до подготовки отдельной транзакции удаления. Нельзя выполнять `TRUNCATE ... CASCADE` до анализа всех зависимостей: затронуть можно не только переписки.

## Второй этап: только после результатов

Подготовить точный SQL с ограниченным набором таблиц, осмысленным порядком удаления, сохранением назначений и проверками. Продумать, нужны ли новые задачи создания чата для **уже назначенных** пар после удаления старых задач: миграция 0039 создаёт задачу при новом назначении, не автоматически для старых пар. SQL удаления не входит в этот PR.

До выполнения удаления создать резервную копию затрагиваемых таблиц или полный snapshot БД и проверить возможность восстановления. Не запускать очистку одновременно с активной отправкой сообщений.
