# Установка 383 изображений нового курса ПДД (PR #126)

Изображения исходных 30 глав перечислены в `tools/pdd-source-images-manifest.json`. PR #126 меняет только админский предпросмотр: сначала пробует локальный URL `/course-import/img/<name>.png`, если файла нет — временно показывает закреплённый источник GitHub. Это **не** означает, что перенос завершён.

## После merge и зелёного CI

Подключиться к серверу и выполнить в указанном порядке:

```bash
cd /var/www/driving-school
git pull --ff-only origin main
python3 tools/import_pdd_images.py
python3 tools/import_pdd_images.py --verify-only
npm run build
```

Скрипт загрузит PNG в `public/course-import/img/`; Vite при сборке скопирует их в `dist/course-import/img/`. Это не удаляет и не заменяет старые статьи или данные учеников. Не выполняйте `git add` для 383 файлов — на сервере они остаются отдельными файлами и не коммитятся.

Проверить после сборки:

```bash
find dist/course-import/img -maxdepth 1 -type f -name '*.png' | wc -l
curl -I https://dvizh-school.ru/course-import/img/i00a1f75098b4.png
```

Ожидается 383 файла и HTTP 200 для контрольного PNG. Проверить несколько иллюстраций в `/admin/pdd/preview` через DevTools Network: обращения должны идти на домен `dvizh-school.ru`. Если источник GitHub всё ещё используется, проверить HTTP-статус локального файла и настройку сервера, вместо того чтобы считать импорт успешным.

**Важно:** на следующем `git pull` незакоммиченные картинки в `public/course-import/img` сохраняются, но для нового сервера перенос нужно повторить. Деплой не должен очищать эти файлы. Если загрузка изображений завершилась ошибкой, не переключайте учеников и повторите команду после устранения причины.

Новый курс учеников не включён. Перед включением нужны резервная копия прежних 38 тем и проверка рендера, тестов и всех изображений.
