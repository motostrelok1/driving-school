# Снимок исходного курса ПДД — PR этапа импорта

Источник: `motostrelok1/edu.dvizh-teory`, commit `d431cc760d8ba4ebdee2824e595436dc8cc56bd2`, blob JSON `0877105a658dcf12374bfa186552be124df05912`.

В папке `public/course-import/sections.json` лежит неизменённая копия исходных учебных данных: **30 тем, 1514 блоков, 30 блоков тестов, 139 вопросов, 392 размещения изображений**. Файл `tools/pdd-source-images-manifest.json` содержит **383 уникальных относительных пути** к изображениям. Все вопросы в источнике имеют корректный индекс ответа.

**Важно:** изображения в этом PR **пока не копируются**. Текущие пути `img/...` указывают на исходный проект; новый курс нельзя переключать до переноса всех 383 файлов или настройки гарантированного хранилища и проверки HTTP 200.

Импорт на этом этапе — staging исходного JSON в репозитории; старые темы в Supabase, страницы курса и редактор не изменены. Отдельный PR должен реализовать новый рендер, загрузить медиа, проверить ссылки и только потом переключить ровно 30 новых тем. Старые 38 тем по решению владельца **не сопоставляются** с новыми, старые отметки чтения не переносятся.

## Проверки до запуска

1. Прогнать `python3 tools/pdd_course_preflight.py public/course-import/sections.json` и удостовериться в нулевом списке проблем.
2. Сопоставить все пути из `tools/pdd-source-images-manifest.json` с реальными файлами `public/img` исходного проекта, проверить размеры/расширения.
3. Проверить 139 вопросов и ссылки на знаки/разметку в новом рендере.
4. Сделать бэкап текущей таблицы `pdd_articles` в Supabase до её изменения; не выполнять SQL-очистку заранее.
5. Только после сквозного теста включить новый каталог; сохранить возможность отката.
