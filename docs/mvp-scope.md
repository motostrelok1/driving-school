# Объем MVP

## Цель

Довести текущий MVP до стабильного состояния без расширения продукта новыми крупными направлениями.

## Входит в MVP

- Авторизация и регистрация через Supabase.
- Роли student, instructor, admin.
- Защищенные маршруты по ролям.
- Кабинет ученика с расписанием.
- Кабинет инструктора с расписанием и учениками.
- Админка с пользователями, ролями, назначением инструкторов.
- Админское создание занятий.
- Базовая работа с группами.
- PWA-сборка и push-кнопка.

## Не входит в текущий MVP

- CRM.
- Кабинет родителя.
- Кабинет директора.
- Чат.
- Оплаты и договоры.
- Полная аналитика.

## Критерии готовности MVP

- Все основные маршруты открываются для нужных ролей.
- Ученик видит свои занятия.
- Инструктор видит свои занятия и учеников.
- Админ управляет ролями, назначениями и занятиями.
- Группы можно хотя бы создать и увидеть.
- Сборка проходит без ошибок.
- Линтер проходит без критичных ошибок.
- Есть минимум базовых задач на тестирование.
