# Course media v1.0.0 — контракт интеграции с Driving School Kit

### Два независимых вида изображений
- `course-media/img/` — 383 версионированных PNG из `img/i*.png`, которые опубликованные блоки ПДД запрашивают как **статические PWA URL** `/course-import/img/i*.png`. Эти файлы не нужно загружать в Supabase Storage.
- `pdd-course-media` — отдельные файлы, которые редактор загружает через Storage API. Для них нужен самостоятельный import/seed этап и проверка ссылок. Текущий скрипт их не устанавливает.

### Когда Core + Kit installer будет готов
1. Выбрать проверенную версию исходников Driving School и совместимую версию `course-media`. Проверить manifest и образ.
2. Установить чистую схему приложения + системные зависимости Auth/Storage/RLS, не импортировать старую БД пользователей.
3. Загрузить учебные текстовые блоки через **отдельный версионированный seed-пакет**. Нынешний `import-test-course-content.sh` использует `cloud-backup.dump` и является процедурой TEST-only, не установщиком новой школы.
4. Собрать PWA в **новый отдельный выходной каталог** и выполнить `python3 scripts/install-course-media.py --target /path/to/staged/dist`. Путь должен уже существовать; скрипт до копирования проверит все 383 SHA-256.
5. Проверить statically served URL `/course-import/img/<file>` на новом домене, Content-Type `image/png`, 383/383 совпадений; опубликованные страницы без сломанных картинок.
6. Только после пройденных тестов атомарно опубликовать новую директорию PWA; не изменять production директорию в процессе проверки. Старая директория остаётся для отката.

Пример на **временной локальной сборке**, без обращения к VDS:

```bash
npm ci && npm run build
python3 scripts/install-course-media.py --target dist
cd course-media && sha256sum -c sha256sums.txt
```

**Важно:** `dist` в примере должен быть заведомо временной сборкой, а не действующим production web root. Не запускать команды на существующем production VDS без отдельного разрешения.

### Проверки и ограничения
CI `course-media-integrity.yml` подтверждает 383 PNG, SHA-256, повторяемость копирования и fail-closed для повреждённого файла. Это не доказывает работоспособность полной установки Lite, поскольку чистая схема, seed учебного контента, HTTPS и Core installer ещё не реализованы.
