# Публикация курса ПДД — безопасный фундамент (этап #121)

Миграция `0044_pdd_course_publication_foundation.sql` создаёт отдельные таблицы опубликованных ревизий и указателей на текущую версию каждого из 30 разделов. Доступ на чтение этих таблиц на этом этапе имеют только администраторы. Права записи из браузера **не предоставлены никому**: это подготовка, а не действующий механизм публикации.

## Важно

- Ни один курсант ещё не переключён на новый курс; `/student/theory/course` и старые статьи `pdd_articles` не меняются.
- Даже после выполнения миграции таблицы будут пустыми. Это ожидаемо.
- Чтобы публиковать, нужен отдельный проверенный RPC с транзакцией, валидацией блоков/картинок/ссылок, историей и возможностью отката.
- Чтобы переключать курсантов, нужно перенести все 383 файла изображений в доступное им хранилище, проверить 30 тем и все 139 вопросов, и добавить управляемый флаг включения нового рендера.
- До переключения необходимо снять резервную копию старого курса.

## Применение

Только после merge PR и зелёного CI: открыть Supabase Dashboard → SQL Editor проекта автошколы → новый запрос → скопировать содержимое `supabase/migrations/0044_pdd_course_publication_foundation.sql` → Run.

В SQL Editor проверить наличие `pdd_course_publications` и `pdd_course_published_revisions`; они должны существовать и пока оставаться пустыми.

Откат схемы делать только после отдельной проверки отсутствия данных; автоматически удалять таблицы не следует.
