# PR #115 — изображения и внутренние ссылки в черновике ПДД

## Установка

После слияния PR выполнить **вручную** SQL из `supabase/migrations/0041_pdd_course_media.sql` в SQL Editor действующего Supabase проекта автошколы. Миграция создаёт отдельный публичный bucket `pdd-course-media` и политики записи только для администратора. В браузере используется обычная пользовательская сессия, service role key не требуется.

После SQL обновить фронтенд:

```bash
cd /var/www/driving-school && git pull --ff-only origin main && npm run build
```

## Проверка

1. Откройте `/admin/pdd/preview`, войдите как администратор, выберите раздел и нажмите «Редактировать черновик».
2. Добавьте «Изображение», выберите PNG/JPG/WebP меньше 10 МБ. Дождитесь URL в поле пути, затем сохраните локальный черновик.
3. Добавьте «Ссылку»: для перехода на другую тему используйте путь `/admin/pdd/preview?section=s2` (или другой исходный ID), для внешней ссылки — HTTPS.
4. Проверьте, что ссылка открывает правильный раздел, а картинка отображается после обновления страницы.
5. Проверьте авторизацию: курсант не должен иметь права загружать в bucket. Ошибка 403 ожидаема. Проверить также, что его страницы ПДД не изменились.

**Ограничения:** загрузки попадают в публичный Storage bucket, но сами черновики остаются в localStorage. Файлы из bucket не удаляются кнопкой удаления блока; автоматическую очистку неиспользуемых файлов сделаем при реализации медиабиблиотеки. Внутренние ссылки ведут только на страницу административного предпросмотра, не на страницы учеников. До публикации нового курса это намеренно.
