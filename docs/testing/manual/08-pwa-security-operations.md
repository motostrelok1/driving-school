# PWA, безопасность, производительность и эксплуатация

## Цель тестирования
Проверить загрузку SPA, обновление PWA, безопасность API, восстановимость данных и мониторинг после cutover.

## Чек-лист раздела

- [ ] Никаких Cloud URL и секретов в бандле
- [ ] Автобэкап и restore

## Исходные данные для группы кейсов
Десктоп Chrome и мобильная PWA, аккаунты трёх ролей; для backup требуется исполнитель VDS без публикации дампов/секретов. Не делать тестовый restore поверх production.
