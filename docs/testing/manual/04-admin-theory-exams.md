# Администратор: редактор ПДД, банк вопросов, экзамены

## Цель тестирования
Проверить публикации/черновики курса и раздел промежуточных проверок с разделением уже работающих и незавершённых функций.

## Чек-лист раздела

- [ ] Черновик и история
- [ ] Медиа и предпросмотр
- [ ] Роли и запрет публикации ученику
- [ ] Банк вопросов
- [ ] Назначения и история официальных экзаменов

## Исходные данные для группы кейсов
Тестовый администратор; отдельный тестовый черновик/раздел в TEST. Не менять опубликованный контент production без заранее утверждённого восстановления. Банк вопросов на миграции содержал 2 keeper-записи — не считать его полным экзаменационным банком.
