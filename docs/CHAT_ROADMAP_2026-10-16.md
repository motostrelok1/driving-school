## Рабочие правила
- Изменения кода через PR, GitHub CI (сборка и линтер) и проверка перед merge; успешный CI **не равен** проверке функциональности и сервера.
- Для SQL/Edge Functions перед применением нужны согласование со вторым тредом, проверка миграционной последовательности, резервные копии и тесты; не выкатить UI, который зависит от ещё не применённого SQL.
- Предпочтительны понятные команды для копирования и поэтапная пользовательская приёмка.
