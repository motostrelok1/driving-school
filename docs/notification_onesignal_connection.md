# Подключение уведомлений через OneSignal

## Короткая схема

Supabase хранит данные приложения, но push-уведомления напрямую не отправляет.
Для push-уведомлений используется внешний сервис, например **OneSignal**.

В проекте уже есть заготовка под OneSignal.

## Что нужно сделать

1. Создать приложение в OneSignal.
2. Настроить Web Push / PWA push-уведомления.
3. Получить в OneSignal:
   - `App ID`
   - `REST API Key`
4. Добавить `App ID` в `.env.local` приложения.
5. В приложении пользователь нажимает кнопку **Уведомления**.
6. Браузер спрашивает разрешение на push.
7. После разрешения нужно сохранить идентификатор подписки пользователя.
8. Когда нужно отправить уведомление, backend вызывает OneSignal API.

## Что хранить в Supabase

В Supabase можно хранить:

- `user_id`
- OneSignal `player_id` или `subscription_id`
- дату подключения уведомлений
- статус подписки
- тип устройства или браузера

## Кто отправляет уведомления

Отправку должен делать backend:

- Supabase Edge Function;
- свой сервер;
- другой безопасный backend.

Нельзя отправлять уведомления напрямую из frontend, потому что для отправки нужен
секретный `REST API Key`.

## Для PWA на телефоне

Пользователь должен:

1. Открыть приложение.
2. Разрешить уведомления в браузере.
3. Иногда установить PWA на главный экран.

После этого браузер сможет получать push-уведомления от OneSignal.
