- [ ] Отмена сохраняет запись в списке и запрещена после начала попытки.
- [ ] Ученик не видит чужие назначения, попытки и ответы; инструктор не видит эти данные.
- [ ] Ученик не может назначить тест, изменить результат или прочитать ключ ответов.
- [ ] При неприменённой миграции окно показывает понятную ошибку с именем SQL-файла.
- [x] Локальные SQL-проверки прав и ограничений добавлены в `supabase/tests/theory_assessments.sql`; запускать только в тестовой БД.

## Принципы архитектуры

- Supabase — источник истины для истории, диалогов, участников, документов, групп и статусов.
- OneSignal — транспорт Web Push, а не хранилище переписки.
- Push и сообщение внутри приложения — связанные, но разные сущности.
- «Доставлено» и «Прочитано» — разные статусы.
- Архитектура должна позволять заменить push-провайдера без потери истории.


## Регресс

После изменений групп обязательно проверить:

- [ ] Удаление пустой группы.
- [ ] Удаление группы с учениками: группа удаляется, у всех участников `group_id = null`.
- [ ] Освобождённые ученики появляются при создании новой группы.
- [ ] Освобождённые ученики появляются при редактировании другой группы.
- [ ] Ученики из других существующих групп не появляются как свободные.
- [ ] В карточке ученика показывается актуальное название группы или «Без группы».


### Регресс автоматических уведомлений

- [ ] При назначении ученика на слот приходит уведомление и запись появляется в истории уведомлений.
- [ ] При переносе забронированного занятия ученик получает новую дату и время.
- [ ] При удалении забронированного занятия ученик получает уведомление об отмене.
- [ ] При переводе занятого слота в «Бронь» ученик получает уведомление о снятии записи.
- [ ] При назначении инструктора из карточки ученика приходит уведомление с ФИО инструктора.
- [ ] Ошибка push не отменяет уже сохранённое изменение расписания.


### Регресс расписания

- [ ] В списке инструкторов показываются все пользователи с ролью «Инструктор».
- [ ] Если инструкторов нет, администратор видит понятное предупреждение вместо пустого списка.
- [ ] Нельзя создать слот в уже прошедшее время текущего дня.
- [ ] Нельзя перенести занятие на прошедшие дату и время.
- [ ] В админском расписании нет вводящего в заблуждение переключателя «Теория / Вождение»: текущий слот-календарь относится только к вождению.
- [ ] Назначение ученика на свободный слот переводит его в booked и отправляет автоматическое уведомление.
- [ ] Перенос/отмена забронированного слота не ломают расписание и сохраняют уведомление в истории.


### План развития расписания

- [x] Режим «Все инструкторы» в админском расписании.
- [x] Пока конкретный инструктор не выбран, показывать на одном таймлайне слоты всех инструкторов отдельными колонками.
- [x] Над каждой колонкой показывать ФИО инструктора.
- [x] Клик по пустому месту в колонке создаёт слот сразу для соответствующего инструктора.
- [x] При выборе конкретного инструктора возвращать обычный одиночный таймлайн.
- [x] На мобильных устройствах использовать горизонтальный скролл по колонкам инструкторов.
- [x] В выборе курсанта: сначала поле поиска, ниже отдельный прокручиваемый список; список всегда раскрывается внутри модального окна вниз.


### Дополнение регресса расписания

- [ ] После изменений слота другим пользователем/устройством расписание обновляется автоматически без ручной перезагрузки страницы.
- [ ] После отмены/снятия записи push приходит, а статус слота меняется в интерфейсе в течение нескольких секунд.
- [ ] Кнопка «Бронь (отмена)» явно означает снятие текущей записи ученика и перевод слота в бронь.


### Регресс режима «Все инструкторы»

- [ ] По умолчанию в админском расписании выбран режим «Все инструкторы».
- [ ] Каждый инструктор отображается в своей колонке с ФИО в заголовке.
- [ ] Слоты каждого инструктора отображаются только в его колонке.
- [ ] Клик по пустому времени в колонке создаёт слот именно для этого инструктора.
- [ ] При выборе конкретного инструктора остаётся одна колонка.
- [ ] На узком экране колонки доступны горизонтальным скроллом.


### Админский layout

- [x] Админка использует всю доступную ширину экрана вместо общего ограничения `max-w-5xl`.
- [x] Левая навигационная колонка администратора сдвинута к краю экрана.
- [x] Левое меню администратора можно сворачивать до узкой панели с иконками и разворачивать обратно.
- [x] Основной контент при сворачивании меню получает дополнительное место по ширине.


### Производительность админки

- [x] Уменьшить объём данных при загрузке списка пользователей: запрашивать только реально используемые поля профиля.
- [x] Добавить короткий cache/staleTime для списка пользователей, чтобы не перезапрашивать его на каждом переходе.
- [x] В админском расписании загружать только слоты выбранного дня, а не всю историю driving_slots.
- [x] Для пользовательского расписания загружать только будущие слоты.
- [x] Снизить частоту фонового обновления пользовательских слотов до 5 секунд, сохранив автообновление.


### Регресс доступа к вождению

- [ ] При закрытии доступа снимается назначенный инструктор.
- [ ] Все будущие booked-занятия ученика освобождаются и становятся доступными снова.
- [ ] По каждому отменённому будущему занятию ученик получает уведомление об отмене.
- [ ] После закрытия доступа ученик получает отдельное уведомление «Доступ к вождению приостановлен».
- [ ] После повторного открытия доступа ученик получает уведомление «Доступ к вождению открыт».
- [ ] При закрытом доступе блок «Инструктор» в профиле ученика скрыт.
- [ ] В профиле ученика есть информационный блок со статусом доступа к вождению.
- [ ] У ученика с открытым «Вождением» кнопка руля в карточке светло-зелёная.
- [ ] Клик по зелёной кнопке отключает «Вождение» и снимает подсветку.
- [ ] Повторный клик снова открывает «Вождение» и возвращает светло-зелёную подсветку.
- [ ] У ученика без доступа пункт «Вождение» отсутствует в меню.
- [ ] Прямой переход на /student/practice при закрытом доступе не даёт пользоваться разделом.
- [ ] Новый ученик создаётся с закрытым доступом к «Вождению».
- [ ] Существующие ученики после применения миграции сохраняют текущий доступ.


### Регресс напоминаний о занятии

- [ ] За ~24 часа до booked-занятия ученик получает push «Напоминание о занятии».
- [ ] В тексте напоминания есть время занятия и ФИО инструктора, если он назначен.
- [ ] Напоминание сохраняется в общей истории уведомлений.
- [ ] Один и тот же слот не получает повторное 24-часовое напоминание.
- [ ] При временной ошибке push следующая попытка Cron может повторить отправку.


### Регресс часового пояса напоминаний

- [ ] Время в push-напоминании совпадает со временем слота в админском расписании.
- [ ] Напоминание форматируется в часовом поясе автошколы (Europe/Moscow), а не UTC Edge Function.
- [ ] В тексте напоминания показывается конкретная дата и время занятия.


### Регресс бронирования слота

- [ ] После первого нажатия «Забронировать» кнопка сразу становится недоступной.
- [ ] После первого нажатия окно записи сразу закрывается.
- [ ] Повторный клик не создаёт второй запрос бронирования.
- [ ] Ученику приходит только одно уведомление «Назначено занятие».
- [ ] При ошибке бронирования показывается предупреждение, а повторная попытка остаётся возможной.
