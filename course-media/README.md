# Course media package — изображения ПДД-курса

Версионированный пакет иллюстраций теоретического курса (ПДД). Раньше файлы
существовали только в собранном `dist/` и не воспроизводились из Git — это
блокировало чистую установку Supabase Lite и новых автошкол.

## Состав

- `img/` — 383 PNG (8-bit RGB), иллюстрации дорожных знаков, разметки и схем.
  Имена совпадают со ссылками `img/i*.png` в блоках `pdd_course_published_revisions`
  (проверено: ровно 383 уникальные ссылки = 383 файла, 1:1, лишних файлов нет).
- `manifest.json` — для каждого файла: размер, SHA-256, ширина/высота (IHDR), MIME.
- `sha256sums.txt` — для `sha256sum -c`.

Версия пакета: **1.0.0** (см. `manifest.version`). Полный архив релиза:
`course-media-v1.0.0.tar.gz`, SHA-256 архива:
`9cc4002a1ce32bce6e2e0b432367f0fb27035bed2d10bf46c99fa7e20e5a3196`.

## Провенанс и проверка

Источник — production `dist/course-import/img`. Копия на тестовом деплое
(`test.dvizh-school.ru/course-import/img`) побайтово идентична. Это учебные
иллюстрации ПДД (не пользовательские файлы); реальные пользовательские
изображения в пакет не включать.

Проверка целостности после любой модификации:

```bash
cd course-media && sha256sum -c sha256sums.txt   # ожидается "383 OK"
```

## Использование установщиками

1. Распаковать/скопировать `img/` в статическую раздачу PWA (`dist/course-import/img`).
2. Сверить копию с `sha256sums.txt` перед публикацией.
3. Медиа-объекты Storage (бакет `pdd-course-media`) импортируются отдельно —
   см. `scripts/import-test-course-content.sh` (этап переноса контента курса).
